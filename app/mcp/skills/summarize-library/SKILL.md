# 生成库概览

你的任务是生成当前库的综合概览报告。报告应让新用户一眼看懂这个库里有什么、最近动态、数据质量如何。

---

## 全局约束

- **只读操作**。不要修改任何数据。
- **中文输出**。报告全文用中文，字段名/标签名保持原样。
- **数字准确**。所有统计数据必须来自实际调用返回，不估算。
- **结构清晰**。用 Markdown 标题分级，用户在聊天窗口能直接阅读。

---

## 可用工具速查

| 工具 / Resource | 用途 |
|---|---|
| `query_projects(action="search", keyword="")` | 获取全部项目摘要 |
| `query_projects(action="count")` | 项目总数 |
| `cabinet://library/info` | 库基本信息 |
| `cabinet://library/stats` | 统计概览 |
| `cabinet://tags` | 全部标签及计数 |
| `cabinet://fields` | 全部字段定义 |
| `manage_libraries(action="list")` | 列出可用库（多库模式） |
| `manage_libraries(action="get_fields")` | 获取字段定义 |

---

## 操作流程

### 第 1 步：收集基础数据

并行调用以下（可以同时发出）：

```
① cabinet://library/info
② cabinet://library/stats
③ cabinet://tags
④ cabinet://fields
⑤ query_projects(action="search", keyword="")
⑥ query_projects(action="count")
```

从返回中提取：
- 项目总数
- 标签总数
- 字段总数（区分系统字段 key 非空 vs 用户字段 key 为空）
- 文件总数（如有 `file_count` 字段则汇总）

---

### 第 2 步：分析标签分布

从 `cabinet://tags` 返回的数据中：

1. 按计数降序排列
2. 取出前 10 热门标签
3. 统计单例标签（仅 1 个项目使用）
4. 检查是否有语义重复的标签对（如 "NLP" 和 "自然语言处理"）

---

### 第 3 步：分析字段概况

从 `cabinet://fields` 返回的数据中：

1. 列出所有用户自定义字段（`key` 为空的），包含 name / type / suggest_enabled
2. 列出系统字段（`key` 非空的），标记为系统保留
3. 如有 `manage_libraries(action="get_fields")` 返回的 `prompt_hint`，一并列出

---

### 第 4 步：分析近期活动

从 `query_projects(action="search")` 返回的数据中：

1. 按 `updated_at` 降序排列
2. 取出最近更新的 5 个项目，显示 title、updated_at、tag 摘要
3. 列出 file_count > 0 的项目数 vs 无文件的项目数

---

### 第 5 步：分析标签覆盖

从全部项目的 tags 数据中：

1. 统计每项目的平均标签数
2. 列出标签数为 0 的项目（未分类）
3. 列出仅有 1 个标签的项目（分类不足）

---

### 第 6 步：生成报告

按以下模板输出：

```
# 📚 库概览

## 基本信息
- 库名称：{从 cabinet://library/info 或 manage_libraries 获取}
- 项目总数：42
- 标签总数：28
- 自定义字段：5 个
- 文件总数：138

## 🏷️ 热门标签（前 10）
| 排名 | 标签 | 使用数 |
|------|------|--------|
| 1    | 学科领域/计算机科学 | 18 |
| 2    | 文献类型/论文 | 15 |
| ...  | ...                | ... |

## 📋 字段概况
### 自定义字段（5 个）
| 字段名 | 类型 | 填写提示 |
|--------|------|----------|
| 作者   | text | 请填作者全名，多个作者用分号分隔 |
| 出版日期 | date | 请填年份或完整日期 |
| ...    | ...  | ... |

### 系统保留字段
标题（title）、描述（description）、标签（tags）

## 📅 最近更新
| # | 项目 | 更新日期 | 标签 |
|---|------|----------|------|
| 1 | xxx  | 2026-06-03 | 文献类型/论文, 学科领域/物理学 |
| 2 | xxx  | 2026-06-01 | 文献类型/代码, 学科领域/计算机科学 |
| ...

## 📊 数据质量
- 未分类项目：N 个（占比 X%）
- 仅有 1 个标签的项目：N 个
- 平均每项目标签数：2.3
- 单例标签（仅 1 项目使用）：K 个

### 标签分布评估
{概括标签分布是否健康；如有标签失衡（大量项目集中少数标签）、语义重复建议合并等}

## 💡 建议
1. {基于以上分析的具体建议，如"优先为 N 个未分类项目添加标签"}
2. {数据处理建议}
3. {库结构建议}
```

---

## 边界处理

| 场景 | 处理 |
|---|---|
| 库为空（0 项目） | 报告 "库中暂无项目" 并结束，不输出其他维度 |
| 标签数为 0 | "热门标签" 和 "标签分布评估" 段写 "暂无标签" |
| 自定义字段数为 0 | "自定义字段" 段写 "暂未配置自定义字段" |
| 项目数 > 200 | 全量拉取可能较慢，可先做统计再分页获取 recently-updated |

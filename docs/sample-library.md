# 样例库与手测清单

`tools/create_sample_library.py` 会按当前 schema 生成一个可丢弃、可反复重建的完整测试库。它用于手工覆盖搜索、标签、字段、文件视图、缺失链接、导入导出、MCP audit、LLM 建议、搜索历史和界面状态持久化。

## 生成与打开

```powershell
python tools/create_sample_library.py --target sample-library --force
```

生成后在应用中选择「库 → 切换库...」，打开 `sample-library/` 目录。

生成目录结构：

```text
sample-library/
  .llm-cabinet
  cabinet.db
  library/              # 仓储模式文件
  external_sources/     # 外链模式文件与重关联测试目标
```

建议把样例库当作一次性测试数据。做过删除、移动、重关联、导入等破坏性操作后，重新运行上面的 `--force` 命令即可恢复初始状态。

## 样例数据

### 字段

默认保护字段之外，脚本会补齐：

| 字段 | 类型 | 主要测试 |
|---|---|---|
| 作者 `author` | text | `author:刘慈欣`、列表列显示 |
| 日期 `date` | date | `date:>=2024-01-01` |
| 评分 `rating` | rating | `rating:>=4` |
| 来源 `source_url` | URL | 项目编辑、导出字段快照 |
| 状态 | text | `状态:待整理` |
| 优先级 | number | 数字字段展示 |
| 负责人 | text | 自定义字段展示 |
| 备注 | textarea | 隐藏字段、项目编辑 |

### 项目

| 项目 | 初始用途 |
|---|---|
| 三体研究资料 | 中文搜索、高分科幻、多层文件夹、generated 封面、空文件夹 |
| 银河帝国整理 | 英文资料、外链文件、科幻标签交集 |
| AI Team Workspace 方案 | 待审阅 LLM 建议、未读 MCP 修改、MCP audit |
| 未分类草稿 | 未分类筛选、纯关键词搜索、外链文件 |
| 缺失链接修复样例 | missing 文件、一致性检查、重关联 |
| 导出导入闭环样例 | copy/link/generated/user origin、同名外链、ZIP/目录导入导出 |
| 空项目边界样例 | 0 文件项目、批量导出灰显、删除确认 |

## 手测清单

### 0. 启动与基线确认

| 勾选 | 操作 | 预期 |
|---|---|---|
| [ ] | 重建样例库并切换到 `sample-library/` | 应用正常打开，无崩溃；状态栏和列表刷新完成 |
| [ ] | 查看项目列表 | 至少看到上表 7 个项目 |
| [ ] | 打开「设置 → 字段」 | 能看到作者、日期、评分、来源、状态、优先级、负责人、备注；备注默认不显示在列表列 |

| [ ] | 搜索 `date:>=2024-01-01` | 命中 2024 年及之后的项目，包括「三体研究资料」「AI Team Workspace 方案」「未分类草稿」「导出导入闭环样例」「空项目边界样例」 |

### 6. 缺失链接与一致性检查

| 勾选 | 操作 | 预期 |
|---|---|---|
| [ ] | 打开「缺失链接修复样例」 | 文件 `missing-target.pdf` 带缺失警告；大小显示为 `—` |
| [ ] | 执行「工具 → 检查库一致性...」 | 报告中显示 1 个失效链接，项目为「缺失链接修复样例」 |

| [ ] | 重建样例库 | 缺失链接恢复为初始状态，便于重复测试 |

### 7. 导出与导入闭环

| 勾选 | 操作 | 预期 |
|---|---|---|
| [ ] | 选中「导出导入闭环样例」，点击工具栏「导出项目」 | 弹出导出对话框；默认导出目录可修改 |
| [ ] | 目录形式导出，勾选「复制链接模式文件」，保留目录结构 | 导出目录中有 `project.json`、`files.json`、`README.md`、`files/` |
| [ ] | 打开 `files.json` | 每个文件条目都有 `subfolder`、`origin`、`is_cover`、`exported_to`；generated 封面 `origin` 为 `generated` |
| [ ] | 检查导出目录 `files/duplicates/` | 两个同名来源文件都被导出，文件名前缀不同，不互相覆盖 |
| [ ] | 再导出一次同一项目到同一目标目录 | 生成自动加后缀的新目录，不覆盖上一次结果 |
| [ ] | 改选 ZIP 打包导出 | 生成 `.zip`；同一天重复导出会自动给 ZIP 文件名加后缀 |
| [ ] | 执行「工具 → 导入项目包...」，选择刚导出的目录包 | 新项目被导入；标题、标签、自定义字段、文件 subfolder、origin 都恢复 |

## 通过标准

- 以上必测项无崩溃、无未响应、无异常命令行窗口。
- 搜索、筛选、编辑、导入导出后的项目和文件数据符合预期。
- 缺失链接、generated 文件、同名文件、空项目、深层目录这些边界样本都能被正确处理。
- 做过破坏性测试后，重新生成样例库能恢复全部初始样本。

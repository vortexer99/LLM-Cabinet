# 02 · 文件列表独立窗口

**工作量**：S  
**优先级**：P2  
**状态**：待做

## 来源
`TODO.md → 🎨 UI / 交互` 第 3 条

## 目标
双击文件区右上角"⇱ 展开"按钮，文件列表脱离主窗口成为独立窗口；关闭后回到三栏布局。

## 实现要点
- 抽出文件表组件为独立 `FilesPanel(QWidget)`，可同时被主窗口与独立窗口持有
- 主窗口加 detach/attach 方法：
  - detach：从右下槽位 takeWidget → 放入新 QDialog → 槽位显示占位提示
  - attach：close 独立窗口 → widget 移回主窗口
- 独立窗口里仍能接收：拖放、右键菜单、预览同步信号
- 关闭独立窗口时自动 attach（避免用户找不回来）
- 主窗口关闭 = 一并关闭独立窗口

## 依赖
- T1 完成后做更顺：保证文件表组件足够自包含
- 不强依赖

## 风险
- 拖放事件过滤器（FilesTableDnD）的父子关系切换时要重新挂载
- 预览面板与文件选中状态的同步要走 signal 而非引用，以防 detach 后 dangling

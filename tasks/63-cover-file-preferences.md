# Task #63：封面文件显示与替换偏好

状态：✅ 完成（2026-11-18）

## 需求

- 默认隐藏生成的封面文件，原始图片设为封面后仍可浏览。
- 设置中选择新封面保存后保留旧封面文件或替换旧封面文件。
- 文件操作失败提供完整文件、路径、阶段、异常和实际保留状态。

## 方案

- 复用项目来源筛选，缺省为仅用户文件；显式保存的 all/user 偏好不变，可切换查看。
- 库级 `cover_replace_generated` 字符串 0/1，默认 0 保留，1 替换。无需 schema 迁移。
- 新封面保存成功后，才将上一张本项目生成封面移到回收站；原始图片、共享引用及不安全路径不删除。回收失败保留文件并提示，不硬删除。
- 图片、视频/PDF 截图、剪切板设置封面共用策略；刷新保留当前预览状态。
- 不追溯清理历史封面；自动导入仍优先保留已有封面。

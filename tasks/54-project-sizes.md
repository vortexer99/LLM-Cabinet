# Task 54 — 项目体积字段

- 来源：用户希望查看项目体积，并支持排序。
- **状态**：✅ 完成，2026-11-16（Unreleased）。
- 约束：只统计项目内已登记文件，含链接及仓储；不自动扫描全库磁盘、不读取文件内容，SQLite 不跨线程；不改 schema。

## 实现

- 内建“项目体积”附加列，默认“未统计”；单个及多选项目右键“更新项目体积”。
- 主线程批量快照已登记文件路径，后台 worker 只 stat 普通文件；不递归目录，不统计未登记文件。同路径重复登记按每条记录累计。
- 缺失、目录及不可访问项不计入已知字节，显示“已知大小／缺失数”；提示包含统计时间。进度按 50ms 节流、每项检查取消，取消整批不保存，原缓存保留。
- 主线程完整完成后原子写入 project_settings JSON（bytes、missing、checked_at、登记指纹）；不改变项目元数据或更新时间，无迁移。
- 刷新只读当前结果的体积缓存；仅对已有缓存的项目分批读取 id/path/is_relative 计算登记指纹，不 stat 磁盘、不构造完整文件对象。新增、移除、路径或存储模式变化后显示“待更新”；局部文件计数更新也会标记过期。磁盘原位修改需用户手动重算，tooltip 明示。
- 体积表头点击按真实字节升降序；未知始终置后，过期和缺失结果按已知字节排序。布局变化迁移持久索引，保留多选、当前项目及预览，筛选后保留排序。后续 task #55 已将排序扩展至所有项目列。

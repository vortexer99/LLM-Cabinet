## T2 · 全局标签管理

### 标签树右键菜单（tag / tag_prefix 节点）

| 菜单项 | 语义 |
|---|---|
| ✏️ 重命名标签… | 全库范围把标签 `A` 改名为 `B`（含 `A/...` 层级标签的整体前缀迁移，tag_prefix 节点同语义） |
| 🔀 合并到… | 把标签 `A` 合并进 `B`：所有带 `A` 的项目改带 `B`（去重），`A` 消失 |
| 🗑 删除标签 | 从所有项目移除该标签（不动项目本身），需确认（显示影响项目数） |

### repository 新增

- `rename_tag(old, new) -> int`（含 `old/...` 前缀批量迁移；返回影响项目数）
- `merge_tag(src, dst) -> int`
- `remove_tag_everywhere(tag) -> int`
- 实现注意：标签存在 `projects.tags`（分隔字符串），逐项目读出-改写-写回，一个事务提交；`new` 已存在时按合并语义去重

### UI 反馈

- 操作后 `refresh_projects()` + statusBar 汇报影响项目数
- 删除/合并前确认框列出"将影响 N 个项目"（#37 的中文确认框，若未做先用现有写法）

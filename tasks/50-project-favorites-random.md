# 50 · 项目收藏与随便看看

**工作量**：S
**优先级**：P1
**状态**：✅ 完成（2026-11-16，Unreleased）

## 来源与目标

用户希望方便地收藏项目，并随机选择当前筛选中的任意项目。

## 实现

- 收藏记录保存在 `project_settings.project_favorite`，值为 `1`；取消删除此键。按库隔离，批量操作原子完成、忽略重复和不存在的项目，不改项目内容与更新时间，无 schema 迁移。
- 网格卡片右上角星标一键切换，拦截星标鼠标事件避免误选、拖拽或双击编辑。列表标题显示收藏星标；两视图通用顶部按钮、Ctrl+D、固定右键目标菜单，支持多选批量收藏或取消。
- 左侧收藏节点与计数，支持 `favorite:true/false`（也可 `1/0`）搜索和补全，可组合标签、文件条件及关键词；普通视图收藏局部刷新不重载预览，收藏筛选中取消立即移出。
- 随便看看通过 `random.choice` 从当前结果模型的项目 ID 等概率选择，含当前项目；清除多选、同步详情并滚动到当前视图目标。搜索防抖先刷新再选择，语法错误阻止抽取，空结果禁用；再次抽中当前项目不重载预览。

- GUI 自测 `gui_project_favorites_random.py`：星标、按钮、快捷键、批量菜单、筛选、候选范围、搜索防抖、空／错误结果、双视图与重启。

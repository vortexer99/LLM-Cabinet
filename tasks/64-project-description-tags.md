# Task #64：项目简介下的标签快捷筛选

状态：✅ 完成（2026-11-18）

## 来源与目标

用户要求在右上项目简介下显示标签，并可点击筛选同标签项目。

## 实现

- 复用标签胶囊样式，自动换行，长名称省略并通过提示显示全文，多标签限制高度并支持滚动。
- 点击或键盘激活标签，复用既有精确标签筛选，搜索文本与侧栏同步，保留其他关键词和文件条件。
- 项目切换、编辑、无标签、无选择及多选时更新显示；重复刷新不重建相同标签。
- 专注／全屏预览隐藏标签，退出按当前项目恢复；筛选保留仍在结果中的项目和预览状态。

# Task #68：项目右键筛选同字段值

状态：✅ 完成（2026-11-19）

## 需求

项目列表中右键作者等字段，快捷筛选同作者、同字段值的项目。

## 实现约定

- 表格右键提供当前单元格字段同值动作；卡片提供非空字段子菜单，支持隐藏字段。
- 根据被右键项目的原始值生成精确搜索，不使用截断文字、标题星标或评分星形显示。
- 标签逐项筛选；空值及附加列不伪造字段查询。
- 捕获本次右键的值，保留其他搜索条件并替换顶层同字段条件，复杂表达式保持原义。
- 特殊名称和值安全转义；解析冲突不能误筛其他字段。

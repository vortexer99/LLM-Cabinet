# Task #67：Shift／Ctrl 标签组合筛选

状态：✅ 完成（2026-11-19）

## 需求

按住 Shift 点击其他标签进行 AND 筛选，按住 Ctrl 点击进行 OR 筛选。

## 规则

- 标签与标签前缀支持组合，依次与当前整个标签组合进行 AND／OR。
- 关键词、文件条件及其他非标签限制保留外层 AND；不能拆坏手工输入的复杂混合表达式。
- 组合状态来自搜索表达式，各参与标签图标同步；手工编辑、刷新、自定义筛选恢复保持一致。
- 重复加入相同正向标签幂等，普通点击仍回到单标签三态，简介标签始终正向定位。
- Shift 与 Ctrl 同时按下优先 AND，鼠标或键盘一次激活只刷新一次。

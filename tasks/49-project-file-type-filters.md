# 49 · 按项目内文件类型筛选

**工作量**：S
**优先级**：P1
**状态**：✅ 完成（2026-11-16，Unreleased）

## 目标与实现

- 左侧独立文件类型区域：“有视频”“有压缩包”，多选可满足任一或全部，清除只影响类型条件。
- 与标签、关键词取交集。后续 task #56 已统一为搜索框完整表达式：“全库”清空查询和筛选，不再保留隐藏条件。
- 内置 `has:video`、`has:archive`，通过参数化 EXISTS 查询项目文件，支持 AND／OR／NOT、补全与现有收藏搜索。
- 类型以已登记 kind 为准，旧 other 兼容已知扩展名，严格匹配路径结尾；不以描述或目录中的扩展名命中。不读物理文件、不检查存在性、不写回旧记录。
- 类型选择本次会话有效；需重复使用的查询可收藏。无数据库迁移。
- 补充：增加“有外部链接文件”与 `has:external`（中文别名 `has:外部链接`），严格按 `files.is_relative=0` 判断；不依赖项目默认存储模式、来源网址或文件是否存在。三个条件支持任一／全部，组合可由不同文件满足；面板标题改为“文件筛选”。
- 界面调整：复用 TagTree 样式，改为可折叠分组和三个树形条目，点击切换高亮、无需 Ctrl 多选；任一／全部与清除移入右键菜单，支持空格切换和 Esc 清除。去掉常驻复选框、下拉框和清除按钮，按实际行高自适应高度。

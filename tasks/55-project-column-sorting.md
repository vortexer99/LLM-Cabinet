# Task 55 — 项目列表全列类型排序

- 来源：用户反馈只有项目体积列能排序。
- 状态：✅ 完成，2026-11-16（Unreleased）。
- 约束：不读取用户数据库；仅显式临时库、合成项目；无 schema 迁移。

## 实现

- 所有项目列表列支持表头点击排序，同列切换升降序，新列从升序开始。
- 原始标题／描述／标签／文本／网址采用自然排序，不受收藏星标、显示截断、单位影响；数字／评分按 Decimal，文件数及体积按整数，日期和更新时间统一按 UTC 时间比较。
- 空值、非法数字／日期及未统计体积在两个方向都置后。
- 迁移持久索引保留当前项及多选，不重建预览。筛选刷新、局部更新沿用排序；以稳定列键跟随字段重排，隐藏／删除该字段时清除排序和箭头。

# Task 53 — 库级预览滚轮切换文件

- 来源：用户希望通过设置选择滚轮是否切换上一个／下一个文件。
- 状态：✅ 完成，2026-11-16（Unreleased）。
- 约束：仅显式临时测试库与合成文件，无 schema 迁移。

## 实现

- 项目库设置的“预览行为”新增 `preview_wheel_navigation`，字符串 `1`／`0`，默认关闭；即时读取当前库设置，无需重启或重选文件。
- 仅在预览画面接管滚轮：向上前一文件、向下后一文件；复用现有导航信号，遵循排序与筛选、首尾不循环。
- 普通滚轮累计 120 角度单位、触控板累计 40 像素，单事件最多切换一个文件；反向／滚动开始或结束时重置累计。
- 关闭时保留图片缩放、PDF 滚动；音量／进度／缩放选项等控制条不接管。

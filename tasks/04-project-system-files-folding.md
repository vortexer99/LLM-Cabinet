# 04 · 项目内系统/衍生文件折叠（二态视图）

**工作量**：S
**优先级**：P1
**状态**：✅ 2026-06-11

## 来源

`TODO.md → 📦 项目 & 文件管理` 第 2 条；`docs/file-handling.md` 评审收尾时敲定的设计方向。

## 目标

项目内文件分两类——**用户添加的文件** vs **软件衍生物**（封面快照、未来的缩略图/摘要等）——用一个简单的视图开关让用户聚焦自己关心的部分，不被衍生文件干扰。

---

## 设计：二态视图（基于 #30 origin）

#### 入口

文件表上方加一个 toggle：

```
[ 👤 仅用户文件 | 🌐 显示所有 ]
```

- 默认 **🌐 显示所有**（新用户首次截 PDF 封面后能立刻看到 `__cover_*.png`，避免"我刚截的图哪去了"的困惑）
- 切到 👤 仅用户文件 → 隐藏 `origin='generated'` 的行
- 状态按项目持久化（`project_settings` 键 `files_view_origin_filter`，值 `user` / `all`）
- **toggle 智能隐藏**：项目内**没有任何** `generated` 文件时，toggle 整体隐藏（避免出现一个看似没用的开关）；一旦该项目出现第一个 `generated` 行（如用户截了封面）→ toggle 出现，初始状态 `all`

#### 为什么二态而不是更多

- 之前讨论过"按 label 识别 / 按扩展名分类 / 手动 category 字段"三套方案
- task #30 已把"用户 vs 衍生"在数据层规范化为 `files.origin`，UI 没必要再发明一套并行的分类
- "用户/全部"两态足够覆盖日常需求；细粒度（按 origin 子类、按扩展名归类）放进后续扩展

## 实现要点

### A. 筛选逻辑（最小改动）

在 `_populate_files_tree` 取数据后、构造 QTreeWidgetItem 前过滤：

```python
files = self.repo.list_files(pid)
has_generated = any((f.origin or "user") == "generated" for f in files)
self._files_origin_toggle.setVisible(has_generated)  # toggle 智能隐藏
origin_filter = self.repo.get_project_setting(pid, "files_view_origin_filter", "all")
if origin_filter == "user":
    files = [f for f in files if (f.origin or "user") == "user"]
self._build_tree_from(files)
```

### B. 视图 toggle UI

放在文件表上方工具条（与 #31b 的"树形/扁平"按钮邻近）：
- `QToolButton` + 两个图标 + checkable
- 点击 → 写 setting → 重 populate

### C. 与 #31b 视图模式的共存

两个视图开关都生效：
- 「树形 / 扁平」 × 「仅用户 / 全部」 = 4 种组合
- 各自独立的持久化键
- 互不干扰

### D. 与封面交互的兼容

- 设为封面的衍生文件（`origin='generated'` 的 `__cover_*.png`）在「仅用户文件」视图下**不可见**
- 但右键"设为封面 / 重置封面"仍正常工作（操作的是 `cover_file_id` 指针，不依赖该文件是否在当前视图）
- 若用户想直接看到封面快照行，切到「显示所有」即可

## 校验

- [ ] 默认进入项目（无 generated 文件）→ toggle 不可见，文件表显示所有文件
- [ ] 项目内截 PDF 生成封面 → 出现第一个 generated 行 → toggle 自动出现，状态 `all`
- [ ] 切到「仅用户」→ generated 行被隐藏
- [ ] 切回「显示所有」→ generated 行恢复可见
- [ ] 删除所有 generated 文件后刷新 → toggle 重新隐藏（但 `files_view_origin_filter` 设置保留，下次 generated 再出现时按上次状态显示）
- [ ] 切到别的项目再切回来 → toggle 状态保持（独立按项目持久化）
- [ ] 项目 A「仅用户」、项目 B「显示所有」→ 互不干扰
- [ ] 在「仅用户」视图下设的封面（指向用户图片）→ 正常显示
- [ ] 在「仅用户」视图下截 PDF 生成封面 → 封面图本身不显示在文件表（被隐藏），但封面正常生效
- [ ] 与 #31b 的视图模式正交：「树形 + 仅用户」「扁平 + 显示所有」等 4 种组合都工作

## 待澄清

> 卡片正文已按"默认决定"写成可执行状态；**若不同意，请在我编码前告知**。

1. **默认状态是「仅用户」还是「显示所有」**
   - 默认决定：**显示所有**（新用户首次截 PDF 封面后能立刻看到 `__cover_*.png` 出现，避免"刚截的图哪去了"的困惑）。
   - 配合"toggle 智能隐藏"——项目无 generated 文件时 toggle 不可见，避免出现一个看似没用的开关。
   - 若你担心默认显示所有让"折叠"功能形同虚设，告诉我改回默认「仅用户」+ 加首次进入项目的一次性 tooltip。

2. **导出时是否尊重视图筛选**
   - 默认决定：**不尊重**（导出是数据完整性操作，UI 视图筛选不应影响）。
   - 若希望「仅用户」视图下导出 = 不包含衍生文件，告诉我，需要在 #28 导出选项里加一个"按当前视图筛选"勾选。

3. **是否支持「仅衍生文件」反向视图**
   - 默认决定：**不做**（用户主动想看自己的封面快照清单的场景少；当前 toggle 切到「显示所有」就能看到，足够）。
   - 若你希望有"调试视图"看所有软件生成的东西，告诉我，把二态升级为三态（仅用户 / 仅衍生 / 全部）。

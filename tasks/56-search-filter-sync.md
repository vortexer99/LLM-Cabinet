# Task 56 — 搜索框与侧栏条件统一

- 来源：用户指出标签筛选未显示在搜索框，二者应等价。
- 状态：✅ 完成，2026-11-16（Unreleased）。
- 约束：只使用显式临时测试库和合成记录，不读取用户数据库；不需要 schema 迁移。

## 实现

- 搜索框为唯一查询来源；点击标签、文件类型、收藏、未分类、待审阅和 MCP 修改均写入可编辑表达式，不再叠加隐藏状态。
- 标签点击精确匹配，父标签使用 `tag_prefix`，保留原有 `tag:` 包含匹配。为特殊字符及布尔关键字转义；前缀 SQL 转义 LIKE 通配符。
- 侧栏仅替换顶层同组条件，保留其他合取项和混合 OR／NOT 语义。手动编辑反向投影可表达的控件状态，复杂条件不伪造单项选择。
- 清空搜索框或点击“全库”清除所有条件；标签树“全部项目”仅清除顶层标签／状态组。历史与收藏直接保存完整查询，可复制复用。
- 程序写搜索框和投影控件时阻断信号，只进行一次轻量刷新；语法错误不覆盖原输入，侧栏操作提示先修正。

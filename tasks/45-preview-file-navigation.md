# 45 · 预览区上一文件 / 下一文件

**工作量**：S
**优先级**：P1
**状态**：✅ 完成（2026-11-15，Unreleased）

## 来源与目标

用户要求右上角预览区提供左右翻页，等同于选择前一个/后一个文件。

## 实现与约束

- 预览组件发出前后导航信号，主窗口按当前文件树的实际顺序选中相邻文件。
- 支持树形与平铺、自然排序/降序/自定义顺序、来源过滤；跳过目录节点，包含折叠目录中的文件，选中时展开父目录。
- 无选中时下一文件从首项开始；空列表、首尾禁用相应按钮，不循环。
- 导航收束为单选并滚动定位，复用文件选择预览路径和当前库自动播放设置。
- 不涉及数据库结构或用户数据修复；验证仅使用独立临时库与构造文件。

# Task 52 — 动态 WebP／GIF 播放预览

- 来源：用户希望支持 WebP 图片播放。
- 状态：✅ 完成，2026-11-16（Unreleased）。
- 约束：不访问用户数据库；无新增依赖，无 schema 变更。

## 实现

- 保留已有静态 WebP 识别与预览；QImageReader 检测多帧动画后由 QMovie 播放，默认不缓存全部帧。
- 动画自动开始，控制条提供暂停／继续；播放独立于视频自动播放设置，有限循环结束后可再次点击播放。
- 换帧更新当前画布内容，不重置缩放和平移；当前帧截图沿用设封面入口。
- 重复选择同一动图不重启或解除暂停；切换／清空停止旧动画并释放文件句柄，静态图隐藏播放按钮。

## 验证

- `gui_animated_images.py` 使用合成红蓝双色 WebP／GIF 和临时静态／损坏文件，无数据库、无网络依赖；45 项通过。
- 相关预览翻页、视频封面播放保持与主窗口回归通过，Python 语法编译通过。

# Task 60 — 搜索补全关闭与清空按钮同步

- 来源：用户反馈点击外部不能关闭补全，以及左侧筛选后清空按钮消失。
- 状态：✅ 完成，2026-11-17（Unreleased）。
- 约束：不得读取用户库，无 schema 变化。

## 实现

- 补全监听外部点击、外部焦点和应用失活；不消费外部点击，保留候选鼠标／键盘选择。
- 原生 hideEvent 同步候选状态，避免隐藏后仍拦截按键；在 Qt 构造前准备主题可能访问的状态。
- 程序填入搜索表达式保留 textChanged，让内置清空按钮正常更新；短暂抑制补全并停止防抖，仅刷新一次查询。

## 验证

- gui_search_popup_dismiss.py：主题下 offscreen 和 Windows 原生各 26 项通过，覆盖外部空白点击、焦点、应用切换、Esc、候选点击／键盘及清空按钮。
- 主窗口、查询同步、左侧收藏、文件类型和扩展名回归通过；测试均使用合成记录与显式临时库。

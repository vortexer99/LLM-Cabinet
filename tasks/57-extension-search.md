# Task 57 — 扩展名组合搜索与命名收藏

- 来源：用户希望把 MP4、WebP、GIF 组合搜索保存为“有视频类型”。
- 状态：✅ 完成，2026-11-16（Unreleased）。
- 约束：不读取用户数据库及媒体内容；测试只使用显式临时库与合成登记路径；无 schema 迁移。

## 实现

- 新增 `ext:`／`ext=` 内置搜索字段，按登记路径末尾精确匹配；可省略点号、不区分大小写，支持复合扩展名、AND／OR／NOT。
- 使用参数化 EXISTS，不因多文件重复项目、不误命中目录或后续附加后缀；包含缺失记录，不按内容区分动图。
- 搜索补全提供 MP4／WebP／GIF 等常见扩展名；复用现有 ☆ 命名收藏及 ⌄ → 收藏入口。
- 推荐查询 `ext:mp4 OR ext:webp OR ext:gif`，AND 版本表示三种格式均存在。

## 验证

- `gui_extension_search.py`：临时库查询边界、组合条件、命名保存／恢复及补全。
- 既有文件类型搜索与侧栏同步回归；Python 语法与 diff 检查。

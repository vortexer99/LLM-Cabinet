## T2 · 即时补全下拉

### 触发与内容

输入过程中在搜索框下方弹出自绘轻量下拉（`QListWidget` 浮窗，样式对齐菜单），按当前 token 给出三类候选，分区显示：

| 区 | 内容 | 触发 |
|---|---|---|
| 字段语法 | `tag:` `rating:` `author:` `date:` 等可用字段前缀 + 操作符提示（`rating:>=`） | 当前 token 匹配字段名前缀，或 token 为空 |
| 标签值 | `tag:` 之后列出库中真实标签（`repo.tag_counts()`，支持层级标签续打） | 处于 `tag:` 语境 |
| 历史/收藏 | 匹配的收藏（☆ 前缀）与最近搜索 | 输入与历史/收藏前缀匹配 |

### 交互

- ↑↓ 选择、Tab/Enter 补全、Esc 关闭；鼠标可点
- 补全字段语法时插入 `tag:` 并把光标留在冒号后，继续触发标签值候选
- 选中历史/收藏项 = 整句替换并立即执行搜索
- 与 200ms 防抖搜索并存：补全只做"提示"，选中才改文本

### 实现要点

- 参考 Qt 官方 `QCompleter` 自定义 popup 模式；候选模型自己喂（不用 QCompleter 的模型，因为要混排三类 + 分区标题）
- 候选数据在弹出时实时查（tag 列表量小），不做长缓存
- 语法错误时：下拉顶部加一行错误提示（替代只有文字变红）

## T3 · 快捷键与配色

- `Ctrl+F`：任意界面聚焦搜索框并全选（`QShortcut` 挂主窗口）
- 语法错误色 `#b00020` → 主题 danger 色（#34 的色板就绪后用色板；未就绪先换成 `#fa5252` 与主题一致）

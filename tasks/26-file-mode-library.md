# 26 · 文件模式库

**工作量**：S+S+S（Phase A/B/C 各半天内）
**优先级**：P1
**状态**：待做

## 来源
用户需求：部分库的文件交叉度高（参考图库、音效素材、代码片段集等），项目作为一级组织单位不合适，文件本身才是一级公民，"项目"应退化为标签。

## 设计核心
**文件模式 = 每个文件就是一个只含 1 个文件的"项目"。** 复用全部现有项目基础设施（元数据、标签、搜索、MCP、导出），只在 UI 上做减法。

| 维度 | 项目模式（现行） | 文件模式（新） |
|---|---|---|
| 导入 | 文件夹/多文件 → 1 个项目 | 每个文件 → 1 个独立项目 |
| 主界面 | 项目列表 + 文件表 | 项目列表（= 文件列表），隐藏文件表区域 |
| 预览 | 文件表选中的文件 | 项目列表选中即预览 |
| 元数据 | 挂在项目上 | 同（项目就是文件） |
| 标签 | 项目级标签 | 同（实现跨文件交叉分组） |
| 添加文件 | 可向已有项目追加文件 | 禁止（每个项目只能有 1 个文件） |

## Phase A · 数据层 + 建库选择（S）

### A1. LibraryHandle 增加模式字段
- `LibraryHandle` dataclass 新增 `mode: str = "project"`（可选 `"project"` / `"file"`）
- `cabinet.json` 序列化/反序列化同步适配
- 读取旧配置缺少 mode 字段时默认 `"project"`（向后兼容）

### A2. 新建库向导增加模式选择
- `NewLibraryWizard` 第一步增加单选："项目模式"（默认） / "文件模式"
- 简明说明文案："项目模式适合一组相关文件归入同一项目；文件模式适合每个文件独立管理、用标签交叉分组"
- 选择后写入 `LibraryHandle.mode`

### A3. Repository / 启动链路感知 mode
- `app/main.py` 或 `MainWindow.__init__` 中把 `mode` 传给 UI 层，控制后续行为

## Phase B · UI 适配（S）

### B1. 主界面布局切换
- 文件模式下隐藏文件表 splitter（右下区域），预览区直接显示在项目列表右侧
- 项目列表列头可考虑改名"文件"或保持不变（待定）

### B2. 预览自动跟随
- 文件模式下 `_on_project_selected` 直接获取该项目唯一文件并展示预览，无需二次点击
- 如果项目 0 文件（理论上不应出现）显示空白提示

### B3. 禁止添加文件
- 文件模式下隐藏"添加文件到项目"入口（工具栏按钮 / 右键菜单 / 拖放到文件表）
- 编辑对话框中文件区域改为只读展示（只显示当前关联的 1 个文件，不可增删）

### B4. 项目列表增强
- 文件模式下项目列表可考虑显示文件扩展名/图标列，方便一眼区分文件类型
- 排序增加"文件大小""文件扩展名"选项（可选，远期）

## Phase C · 导入适配（S）

### C1. 批量导入行为变更
- 文件模式下"导入文件夹"递归收集所有文件，**每个文件创建一个独立项目**
- 项目标题默认取文件名（不含扩展名），描述留空
- 存储策略（链接/仓储）复用现有逻辑不变

### C2. 单文件导入
- 文件模式下"添加项目"流程简化：直接选文件 → 创建项目（跳过项目标题输入，自动取文件名，可后续编辑）

### C3. MCP 导入
- MCP `manage_project(action="create")` 在文件模式库中，自动限制只能关联 1 个文件
- `manage_files(action="add")` 如果目标项目已有文件，返回错误提示"文件模式下每个项目只能有一个文件"

## 不做范围
- 不支持运行时切换已有库的模式（项目模式 ↔ 文件模式），只在建库时选定
- 不做"一个文件属于多个项目"（标签已经满足交叉分组需求）
- 不做文件级自定义字段（复用项目级字段即可）
- 不做文件内容全文索引（留给 #07）

## 依赖
- 无 schema 变更（mode 存在 `cabinet.json` 的 `LibraryHandle` 中，不进 SQLite）
- Phase B/C 依赖 Phase A

## 风险
- 用户在文件模式库里手动通过 DB 操作给一个项目加了多文件 → 需要在 UI 层兜底只展示第一个文件
- "项目"这个词在文件模式下可能对用户造成困惑 → 考虑在文件模式下 UI 中将"项目"替换为"文件"（Phase B 中可做）

## 验收
- 新建"文件模式"库，导入一个包含 10 个文件的文件夹 → 产生 10 个项目（各含 1 文件）
- 主界面无文件表区域，点击项目列表中的条目直接预览文件
- 可以给文件打多个标签，通过标签交叉筛选
- 所有现有功能（搜索、MCP、导出、批量操作）正常工作
- 项目模式库行为不受影响（完全向后兼容）

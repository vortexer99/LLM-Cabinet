# Task #66：左侧标签三态轮切

状态：✅ 完成（2026-11-19）

## 目标与实现

- 左侧标签及前缀分组点击轮切：包含、不包含、不筛选。
- 搜索表达式作为唯一状态来源，负向条件使用 NOT，标签树显示排除标识。
- 标签及前缀提供直接绘制的状态图标：勾表示包含，减号表示不包含，空心圆表示不筛选，避免字体缺字导致图标消失。
- 三态转换保留其他关键词和文件条件，程序刷新不触发重复筛选。
- 支持键盘回车／空格，右键菜单和折叠不推进三态。
- 简介标签保持正向快捷筛选；其他侧栏入口不改变语义。

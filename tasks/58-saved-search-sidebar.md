# Task 58 — 左侧自定义筛选入口

- 来源：用户希望“有视频类型”等搜索收藏显示在左侧。
- 状态：✅ 完成，2026-11-16（Unreleased）。
- 约束：复用当前库搜索收藏，无 schema 迁移；不读取用户库。

## 实现

- 标签树增加“自定义筛选”分组，列出已有搜索收藏名称，悬停显示完整表达式。
- 点击直接恢复完整查询，按 AST 匹配当前条目高亮；同查询多名称时优先保留本次选择。
- 保存、同名覆盖、删除后立即刷新侧栏，不重载项目预览或改变正在编辑的查询。
- 复用 ☆ 保存和 ⌄ 删除收藏，无重复存储；重开恢复、不同库互相隔离。

# Task #69：外置媒体离线预览与恢复

**状态**：✅ 完成（2026-11-19）

## 已确认范围

数据库位于本机、图片／视频／PDF 文件位于外置设备。数据库本身离线另行处理。

## 方案

- 保留无法访问文件的路径和记录，不误判为未选择，不自动写永久缺失标记。
- 预览区提供重试、完整详情／复制与当前文件重关联入口；重复失败不弹模态框。
- 当前文件后台有界探测，不扫描库、不阻塞 GUI；切换／关闭使用代际隔离迟到结果。
- 静态图片已载入时可以保留画面并标离线；视频记住位置与原播放状态，PDF 记住页码。
- 自动重连恢复后暂停视频，手动重试按此前状态恢复，加载就绪后再恢复位置。
- 解码失败与访问失败分开；错误不能触发循环／下一文件。

## 验证

- 使用独立临时库、合成媒体和模拟不可访问／迟到信号，不读取用户数据库。
- 覆盖首次缺失、播放中失联、恢复、权限错误、解码错误、过期结果、关闭与原媒体行为回归。
- `gui_preview_offline.py`：124 项通过；真实合成图片／视频／PDF，模拟设备失联与慢读取。
- `gui_preview_media_errors.py`：18 项通过；媒体错误与过期回调隔离。
- 原媒体行为回归：媒体设置 76、截图保持播放 360、封面替换 119、动图 45、文件导航 38、放大预览 34、播完动作 90、滚轮 21、自动选择首文件 28 项通过。
- 现有同步预览测试改为等待后台可访问性检查后再断言加载结果；语法检查通过。

## 边界

- 当前文件每 5 秒检查一次；检查超过 4 秒报告超时。后台至多 4 个守护线程，关闭不等待阻塞的文件检查。
- 可访问性检查不会读取数据库或扫描整个库，也不会写入永久缺失标记。
- 检查通过后仍由 Qt 媒体组件加载／解码；本次未改造为隔离进程解码，也未实测物理硬盘热拔插。

# 44 · 库级自动封面与视频自动播放

**工作量**：S
**优先级**：P1
**状态**：✅ 完成（2026-11-15，Unreleased）

## 来源与目标

用户希望按库选择：导入新项目时自动取第一张图片作封面，选中视频时自动播放。

## 实现与约束

- 设置 → 项目库新增两个即时保存开关，键为 `import_auto_cover` / `video_autoplay`，字符串 `"1"` / `"0"`，默认 `"0"`。
- 仅新项目导入自动选图，逻辑目录及文件名自然顺序；优先保留原封面，跳过非图片、缺失和衍生文件。
- 共用导入策略覆盖文件夹/ZIP 三阶段导入和拖放新建项目，不修改历史项目或添加文件行为。
- 视频预览每次选择读取当前库设置；关闭时保留原手动播放行为，切换文件/项目仍停止视频。
- 2026-11-16 修正：重复请求当前视频时跳过停止/重载/自动播放，保持进度和暂停状态；切换文件或清空后再次选择才按偏好加载，回归覆盖重复通知和切换后重新选择。
- 2026-11-16 修正：手动截图设封面后仅局部更新项目，保留视频选择和播放器状态；生成图片不会自动选中。`gui_cover_playback.py` 覆盖树形/平铺、来源过滤和连续截图。
- 复用 settings，无数据库结构变化，不增加 schema 版本。
- 后续扩展：无图片时的视频首帧封面子选项见 [task #47](./47-video-auto-cover.md)，主开关仍为 `import_auto_cover`。

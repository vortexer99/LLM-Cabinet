# Task 61 — 视频播放结束动作

- 来源：用户要求设置视频播完后循环、下一个或停止。
- 状态：✅ 完成，2026-11-17（Unreleased）。
- 约束：设置按库保存，无 schema 迁移；只使用合成媒体和显式临时测试库。

## 实现

- 设置 → 项目库 → 预览行为提供视频播放结束后下拉框，`video_end_action` 为 `stop`（缺省）、`loop` 或 `next`，异常值回退停止。
- 仅自然 EndOfMedia 触发；延迟至状态转换完成后派发，绑定控件生命周期并校验媒体代次、当前源、当前选中文件，避免换项目／停止／加载失败误连播。
- 循环复用当前播放器回到开头；下一个按既有导航排序和来源过滤选择下一文件，视频强制播放，其他类型正常预览，末尾停止，不跨项目或绕回。
- 独立于 video_autoplay，手动选中与自动续播可分别配置；重复路径登记仍可继续播放。

## 验证

- `gui_video_end_action.py`：显式临时库、合成短视频验证自然播完和设置隔离、过期回调、停止／换项目保护。
- 现有媒体设置、文件导航、专注全屏及视频播放保持回归。

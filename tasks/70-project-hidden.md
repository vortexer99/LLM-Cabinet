# Task #70：隐藏项目

**状态**：✅ 完成（2026-11-19）
**工作量**：S
**优先级**：P1

## 功能

- 列表／网格右键隐藏或取消隐藏，支持多选；混合选择提供两种操作，目标固定为菜单打开时的项目。
- 左侧“隐藏项目”入口找回隐藏项。普通列表、搜索、收藏和随便看看默认排除隐藏；显式查看隐藏时随机浏览仍遵循当前结果。
- `hidden:true`／`hidden:1` 仅隐藏，`hidden:false`／`hidden:0` 仅可见，`hidden:all` 包含全部，可与标签、类型、关键词及 AND／OR／NOT 组合并保存为自定义筛选。
- 搜索出现有效的显式 hidden 条件时按完整表达式查询；否则附加默认可见范围。“全库”清空搜索后回到默认可见项目。
- 普通侧栏类别与标签计数排除隐藏，隐藏入口独立显示全部隐藏项目数量。
- 隐藏标记存入 `project_settings.project_hidden`，按库保存；不修改文件、项目元数据、收藏或更新时间，无 schema 迁移。
- 导出、维护、按 ID 访问仍使用全库数据，避免隐藏导致文件记录遗漏。
